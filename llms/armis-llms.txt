# Armis

> Armis is a cyber exposure management and asset intelligence company. Its Armis Centrix platform discovers, protects, and manages every physical and virtual asset — IT, OT, ICS, IoT, IoMT, cloud, and applications — and exposes that intelligence through a tenant-scoped REST API, official SDK/CLI, and MCP servers. This llms.txt was generated by the API Evangelist enrichment pipeline from the repo artifacts.

## Developer surface
- [Developer Portal](https://developers.armis.com/): Register a vendor/integration and obtain API credentials.
- [Trust Center](https://trust.armis.com/): Certifications and compliance (SOC 2, ISO 27001/27017/27018/42001, FedRAMP, DoD IL5, CSA STAR).
- [GitHub Organization](https://github.com/ArmisSecurity): Official open-source clients and tools.

## Authentication
- OAuth2 client-credentials -> short-lived JWT bearer, tenant-scoped `audience` (e.g. https://acme.armis.com/). Env: ARMIS_AUDIENCE, ARMIS_CLIENT_ID, ARMIS_CLIENT_SECRET, ARMIS_VENDOR_ID, scopes. Token endpoint: POST /api/v1/auth/token.
- Legacy API token + tenant id (armis-cli --token/--tenant-id).

## SDKs and CLI
- [armis-sdk (Python)](https://pypi.org/project/armis-sdk/): `pip install armis_sdk` — official SDK. Docs: https://armis-python-sdk.readthedocs.io
- [armis-cli (Go)](https://github.com/ArmisSecurity/armis-cli): `brew install armissecurity/tap/armis-cli` — enterprise AppSec scanning CLI (SBOM/VEX/SARIF, supply-chain protection, CI/CD).

## MCP servers
- [armis-knowledge-mcp](https://github.com/ArmisSecurity/armis-knowledge-mcp): AppSec knowledge MCP + shell-skills bundle. Install: `/plugin marketplace add ArmisSecurity/armis-knowledge-mcp`.
- [armis-appsec-mcp](https://github.com/ArmisSecurity/armis-appsec-mcp): Real-time code/file/diff security scanning MCP (scan_code, scan_file, scan_diff, approve_findings, debug_config).
